# Workbook Everything

One handout the reader can follow and recall before the exam: the logic reads as a chain of questions, and every key point has a diagram.

## Steps

### 1. Read

Read every source given: textbook sections, lecture slides, notes, past papers. Photos have no text layer, so read them by eye. The range and the priorities come from the user, the teacher or the syllabus, and the handout stays inside that range. Past papers show question types, never the range.

Done when every source has been read and the range is stated with who set it.

### 2. Write

Each section heading is the question its topic answers ("the membrane alone would burst: what holds it?"), so recalling the question leads back to the answer. The same idea in another chapter gets a one-line pointer.

- **Mechanism first.** Say who pushes what and why, then name the term. A word used in two contexts gets the difference stated.
- **Arrow chains** say what passes along them.
- **Every part** says where it sits and what has it: all of them, or only some.
- **Comparisons** are tables.
- **Notes from earlier students** get checked against the book, with a list of the places where copying them would lose marks.
- **Anything from outside the sources** wears a visible tag.

Done when every topic in the range has a section and each fact traces to a source or a tag.

### 3. Draw

Every key point gets a diagram of its mechanism. Reuse the course's figures first; otherwise redraw from the book and cite the source figure. Label every shape, so nothing in a figure is left to guess, and check the drawing against the book.

Done when every key point has a figure and every figure has been looked at.

### 4. Past papers, when given

Each question gets its text as printed, the shortest answer that earns full marks, and a diagram. The printed scoring rule sets the length. Print how many papers test each topic so the hot ones stand out, and check what the user remembers about the exam against the papers.

Mark what falls outside the range or outside the current book. **A zero hit proves nothing yet**: try synonyms, the concept under its current name, figure labels and words broken by text extraction before calling something absent.

On request, add a question-only practice paper with writing space.

Done when every question on every paper has an answer.

### 5. Deliver

A PDF in the user's language, ending with a one-page list for the last ten minutes. For the look of an earlier handout, read [references/layout.md](references/layout.md).

Done when every page has been rendered and looked at.
